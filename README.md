# KOVALENKO — demo

Catálogo de calzado en ruso, basado en el diseño proporcionado.

Abre `index.html` o sirve la raíz como web estática. No requiere instalación ni compilación.

Incluye búsqueda, categorías, selección de tallas, carrito y pantalla de pago demo. La pasarela de pagos no está configurada; no se cobran pagos ni se envían pedidos reales. Productos y precios provisionales.
